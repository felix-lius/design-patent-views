# 自测清单（给接收方 agent）

> 这个技能包交给你做验收测试。按顺序跑，全部通过才算装好。
> **不要修改 `_internal/`、不要升级/降级依赖版本、不要把模型上传到任何在线服务。**

## 0. 先判断本包是哪种形态

| 包根目录里有 | 形态 | 调用方式 |
|---|---|---|
| `patent-cli.exe` + `_internal/` | A 自包含版 | `patent-cli.exe ...`（无需 Python） |
| 只有 `scripts/` + `install_deps.py` | B 轻量版 | `python scripts/patent_cli.py ...` |

B 版先装依赖（详见 `INSTALL.md`）：

```bash
python install_deps.py          # 只装缺的，OCP 约 91MB
python install_deps.py --check  # 四项全 ✓ 才算成功
```

> ⚠️ `python scripts/patent_cli.py --help` 能打印帮助**不代表依赖装好了**——
> OCP 是延迟导入的。判定一律以 `install_deps.py --check` 为准。

## 1. 命令行能起来

```bash
patent-cli.exe --help          # A 版
python scripts/patent_cli.py --help   # B 版
```

期望：列出 `auto / analyze / render / dxf / check / run` 六个子命令，退出码 0。

## 2. 冒烟测试：一步出图（核心验收项）

```bash
patent-cli.exe auto --step examples/powerbank.step --front +Y --up +Z --quiet --json-out out.json
```

期望：

- 退出码 **0**
- `out.json` 里 `"ok": true`
- `check.summary.fail` 为 **0**（本机基准：pass 25 / warn 0 / fail 0 / na 8）
- 耗时约 **8–15 秒**
- 产出：
  - `output/powerbank/submission/` 下 **7 张 .jpg**（front/back/left/right/top/bottom/iso）
  - `output/powerbank/all_views.dxf`
  - `logs/05_powerbank.json`（33 项自检报告）

> 输出目录落在**当前工作目录**下的 `output/`、`logs/`，可用环境变量 `PATENT_OUT_DIR` 改。
> OCP 会往 stdout 打 C 层错误信息，**解析 JSON 时务必用 `--quiet` + `--json-out`**。

## 3. 方位引导（退出码 2，不是报错）

```bash
patent-cli.exe auto --step examples/powerbank.step --quiet --json-out o.json
```

期望：退出码 **2**，`o.json` 里 `"need": "orientation"`，并给出 `previews`（6 张方向缩略图路径）。
正确做法是**把图给用户看并问哪张是正面**，拿到答案后重跑第 2 步。

## 4. 多实体引导（退出码 2）

```bash
patent-cli.exe auto --step examples/sample_product.step --front +Y --up +Z --quiet --json-out s.json
```

期望：若该模型为单实体则直接退出码 0；若为多实体则退出码 2 且 `"need": "solid_selection"`。
此时加 `--solids-filtered` 可声明「确认全量出图」并重跑。

## 5. 错误路径（退出码 3）

```bash
patent-cli.exe auto --step 不存在的文件.step --quiet
```

期望：退出码 **3**，JSON 里带 `error`，**不崩栈**。

## 6. 交付物自检

- [ ] 7 张 jpg 尺寸 1772×2598（150×220mm @300DPI）
- [ ] 图内**无任何文字/图号/标注**
- [ ] 只有均匀实线，无虚线/中心线/尺寸线
- [ ] `logs/05_*.json` 中 `fail` 为 0；有 `warn` 必须如实转告用户，不要只说「出好了」
