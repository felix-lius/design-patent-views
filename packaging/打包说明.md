## 二、构建方法

一条命令搞定：

```bash
python packaging/build.py
```

它会依次完成：

1. 清理旧产物
2. PyInstaller 构建 onedir 包（约 45 秒）
3. **把 `examples/powerbank.step` 和文档复制到包根目录** —— 这样用户/agent
   可以在包根目录直接跑 `patent-cli.exe auto --step examples\powerbank.step` 冒烟测试
4. 生成 `dist/design-patent-views-win64.zip`

产物：

```
dist/patent-cli/                 292 MB，包根目录含：
  ├─ patent-cli.exe              主程序
  ├─ _internal/                  运行库（不能删）
  ├─ examples/powerbank.step     冒烟测试用示例
  ├─ SKILL.md / INSTALL.md / README.md / 安装.md
dist/design-patent-views-win64.zip  92 MB  发布包
```

> 早期版本用 `packaging/build.ps1`，但 PowerShell 执行策略会拦截，
> 现改为 `build.py`，跨平台且无此问题。

## 三、踩过的坑（重要，别再犯）

### 坑 1：不能裁剪 OCP 的"可视化" DLL

曾尝试剔除 `vtk*` / `TKOpenGl` / `TKService` / `_avif` / `libwebp` 等，
理由是"本工具只做 HLR 几何投影，不需要 3D 渲染"。

**结果：`import OCP` 直接报 `DLL load failed while importing OCP: 找不到指定的模块`。**

原因：OCP 打包成**单个大 pyd**（`OCP.cp312-win_amd64.pyd`，111MB），
这些库是它的**静态/延迟加载依赖**，无法从功能上推断取舍。
体积一度从 292MB 降到 224MB，但换来一个完全跑不起来的包。

> **教训：292MB 是可靠下限。想减体积，唯一安全的方向是换更小的几何内核，
> 而不是裁剪 OCP 的依赖。**

### 坑 2：不能排除 `unittest`

`ezdxf` → `pyparsing` → `pyparsing.testing` → `unittest` 有硬依赖链。
排掉 `unittest` 后，DXF 导出直接 `ModuleNotFoundError`。

### 坑 3：`collect_all('OCP')` 返回 0 个 binaries

OCP 的包结构特殊，`collect_all` 抓不到它的 binaries（只拿到 datas）。
好在 PyInstaller 自身的分析补齐了必需的 189 个 dll/pyd，
**不要因为 `[spec] OCP 二进制: 0 -> 0` 就以为出错了**。

### 坑 4：中文输出乱码

打包后 stdout 跟随控制台代码页（中文 Windows 是 cp936），中文变乱码。

**解决**：
1. `sys.stdout.reconfigure(encoding="utf-8", errors="replace")`
2. JSON 输出用 `ensure_ascii=True`（中文转 `\uXXXX`，**任何编码下都不会乱码**，
   agent 解析后仍是正确中文）

### 坑 5：输出目录不能写在 exe 旁边

打包后 `pipeline.py` 原本把 output/logs 放在 exe 目录，
装到 `Program Files` 会因无写权限失败（实测 `PermissionError: WinError 5`）。

**解决**：打包模式下 output/logs 落到**当前工作目录**，
可用环境变量 `PATENT_OUT_DIR` 覆盖。

## 四、验证清单（每次重新打包后跑一遍）

```powershell
# 1. exe 能启动
.\dist\patent-cli\patent-cli.exe --help

# 2. OCP 能 import（关键！）
.\dist\patent-cli\patent-cli.exe analyze --config job.json --quiet

# 3. 完整流程
.\dist\patent-cli\patent-cli.exe run --config job.json --quiet
#    期望：ok=true，7 张 submission/1-主视图.jpg … 7-立体图.jpg，all_views.dxf 存在

# 4. 环境独立性（清空 Python 变量后仍能跑）
$env:PYTHONHOME=$null; $env:PYTHONPATH=$null
.\dist\patent-cli\patent-cli.exe analyze --config job.json --quiet

# 5. 杀软误报检查
#    用 Defender / 360 / 火绒 各扫一次 exe
```
